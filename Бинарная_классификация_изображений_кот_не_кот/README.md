# Cat Classifier - бинарная классификация изображений "кот / не кот"

## 📋 Описание проекта

Проект посвящён построению бинарного классификатора изображений, который определяет, изображён ли на картинке кот. В проекте используется техника **transfer learning**
на основе предобученной свёрточной нейросети **DenseNet201**, уже обученной на датасете ImageNet (1000 классов).

Вместо обучения сети с нуля используется готовый backbone: исходный классификатор на 1000 классов заменяется на один выходной нейрон с активацией "sigmoid", выдающий 
вероятность класса "кот". Все слои backbone'а замораживаются, кроме последних 10, которые дообучаются под новую задачу(**fine-tuning**). Дополнительно применяется 
**аугментация данных** - повороты, сдвиги и отражения - для борьбы с переобучением.

---

## 🎯 Цель

Разработать высокоточную модель для классификации изображений как содержащих или не содержащих кота, минимизируя количество ложных срабатываний и пропусков, и 
продемонстрировать полный пайплайн работы с предобученной нейросетью в TensorFlow/Keras.

---

## ✅ Задачи проекта

- Провести проверку исходной предобученной модели DenseNet201 на тестовом изображении
- Заморозить слои backbone'a и настроить fine-tuning последних 10 слоёв
- Заменить финальную активацию и собрать итоговую модель с бинарным классификатором
- Подготовить данные и разбить их на train / val / test
- Настроить аугментацию данных через "ImageDataGenerator"
- Обучить модель метриками accuracy, precision, recall, F1
- Оценить качество на тестовой выборке
- Продемонстрировать инференс обученной модели на реальном изображении

| Признак (папка)      | Описание
|----------------------|------------------------------------------------------------------|
| "cats/"              | Изображения с котами → метка **1**                               |

## 📈 Основные шаги анализа

1. **Установка и импорт библиотек**
- Установка необходимых пакетов ("tensorflow", "pillow")
- Импорт библиотек для работы с изображениями, построения нейросетей и визуализации

2. **Фиксация случайности**
   Задание фиксированных seed'ов для "numpy", "tensorflow" и "random ("seed=17")
   для обеспечения воспроизводимости результатов.

3. **Загрузка предобученной DenseNet201**
   Загрузка архитектуры "DenseNet201" с весами ImageNet (1000 классов).
   Вывод структуры модели для контроля корректности сборки.

4. **Проверка исходной модели на тестовом изображении**
   Загрузка изображения, приведение к размеру 224х224, конвертация в массив, добавление
   batch-размерности, нормализация под DenseNet. Получение предсказания и декодирование
   классов.

5. **Заморозка слоёв backbone'a**
   Перевод всех слоёв DenseNet201 в нетренируемый режим, чтобы сохранить предобученные веса
   при обучении на новом датасете.

6. **Разморозка последних 10 слоёв (fine-tuning)**
   Последние 10 слоёв делаются обучаемыми - сеть адаптирует высокоуровневые признаки под конкретную
   задачу. Число 10 - гиперпараметр, требующий подбора.

7. **Замена финальной активации**
   Последний слой исходной модели использует softmax для 1000 классов. Активация заменяется на relu,
   так как softmax для бинарной задачи не подходит.

8. **Сборка итоговой модели**
   Модель собирается последовательно: сначала идёт вся DenseNet201 как один слой, затем - бинарный классификатор
   с одним нейроном и активацией sigmoid. Вывод структуры для контроля итоговой архитектуры.

9. **Определение метрик и компиляция**
   Помимо стандартной бинарной точности, определяется Precision, Recall, F1-метрика. Компиляция с оптимизатором Adam и низким
   темпом обучения, функцией потерь binary crossentropy и набором метрик.

10. **Препроцессинг изображений**
    Написание функции, которая загружает изображение в разрешении 224х224, конвертирует его в массив и применяет нормализацию.

11. **Загрузка и подготовка датасета**
    Загрузка zip-архива, распаковка, формирование двух списков пар "картинка - метка": для котов (метка 1) и для не-котов (метка 0).
    Объединение и перемешивание списков

12. **Разделение данных на train / val / test**
    Разбиение итогового массива в пропорции 70 % / 15 % / 15 % с помощью вспомогательной функции.

13. **Настройка аугментации данных**
    Создание генератора изображений с параметрами: поворот до 45°, сдвиг по горизонтали и вертикали до 20 %, горизонтальное
    и вертикальное отражение. Расчёт статистик по обучающей выборке.

14. **Настройка колбэков**
    Объявление TensorBoard для логирования метрик и ReduceLROnPlateau для снижения learning rate в 10 раз при стагнации
    val_loss в течение 10 эпох.

15. **Обучение модели**
    Обучение 50 эпох, батчами по 16 изображений, через генератор с аугментацией. Ограничение числа батчей за эпоху, отслеживание метрик
    на train и val.

16. **Оценка на тестовой выборке**
    Оценка обобщающей способности модели на отложенной тестовой выборке - независимая проверка качества.

17. **Демонстрация инференса**
    Финальное предсказание на тестовом изображении - наглядная демонстрация применения обученной модели.
