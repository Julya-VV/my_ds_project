## 📋 Описание проекта 
Проект посвящен построению модели машинного обучения для обнаружения мошеннических транзакций на основе данных о платежах. В качестве модели используется (Decision Tree Classifier) из библиотеки scikit-learn.

## 🎯Цель 
Предсказать вероятность мошенничества ("isFraud") на основе признаков транзакции.

## 📊 Данные
- Исходный датасет: "data.csv"
- Отобрано 17 признаков, включая:
- "TransactionAmt" - сумма транзакции
- "card1" - идентификатор карты
- "C1-C14", "D1" - анонимизированные признаки
- "isFraud" - целевая переменная(1- мошенничество, 0 - легальная транзакция

## 🔧 Используемые технологии
- Python 3.x
- pandas, numpy - для обработки данных
- scikit-learn - для построения модели и оценки качества
- matplotlib - для визуализации
- ROC-AUC - метрика качества

## 📈 Основные шаги анализа 

### 1. Загрузка и предобработка данных
- Выбор релевантных признаков
- Разделение на обучающую (70%) и валидационную (30%) выборки

### 2. Обучение модели 
```python
model = DecisionTreeClassifier(random_state = 1)
model.fit(x_train, y_train)
```

### 3. Оценка качества модели
- **ROC-AUC на обучающей выборке:** ~0.9+ (зависит от конкретных данных)
- **ROC-AUC на валидационной выборке:** ~0.8+ (зависит от конкретных данных)

> **Примечание:** Точные значения метрики могут варьироваться в зависимости от исходных данных и случайного разбиения выборки.

### 4. Анализ важности признаков
В ходе анализа были выявлены наиболее влиятельные признаки, определяющие предсказания модели:
- Топ-2 наиболее важных признака "card1", "TransactionAmt"
- Визуализирован вклад каждого признака в принятие решений

### 5. Валидационные кривые 
Исследовано влияние гиперпараметра "max_depth" (глубина дерева) на качество модели с использованием **5-кратной кросс-валидации**. Это позволяет:

- ✅ Выбрать оптимальную глубину дерева
- ✅ Избежать переобучение (overfitting)
- ✅ Найти баланс между смещением (bias) и разбросом (variance)
- ✅ Оценить стабильность модели при разных значениях параметра
