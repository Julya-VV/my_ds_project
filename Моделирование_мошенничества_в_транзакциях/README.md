# Моделирование мошенничества в транзакциях

## 📋 Описание проекта 
Проект посвящен построению и сравнению моделей машинного обучения для обнаружения мошеннических транзакций на основе данных о финансовых операциях.
В проекте используются два мощных алгоритма градиентного бустинга: **XGBoost** и **CatBoost**.

## 🎯 Цель 
Разработать высокоточную модель для классификации транзакций как мошеннических или законных, минимизируя количество ложных срабатываний и пропусков мошенничества.

## Задачи проекта 
1. Провести исследовательский анализ данных (EDA)
2. Подготовить данные для обучения моделей
3. Обучить baseline модели XGBoost и CatBoost
4. Оптимизировать гиперпараметры для улучшения качества
5. Сравнить производительность моделей
6. Визуализировать результаты обучения
7. Провести кросс-валидацию для оценки стабильности

## 📊 Данные
- **Исходный датасет**: "data.csv"
- **"TransactionAmt"** - сумма транзакции
- **"card1"** - идентификатор карты
- **"C1-C14"**, **"D1"** - анонимизированные признаки
- **"isFraud"** - целевая переменная(1- мошенничество, 0 - легальная транзакция

## 🔧 Используемые технологии
- **XGBoost**: Градиентный бустинг с оптимизацией для больших данных
- **CatBoost**: Градиентный бустинг с автоматической обработкой категориальных признаков
- **Scikit-learn**: Для разделения данных и вычисления метрик
- **Matplotlib**: Визуализация результатов обучения

## 📈 Основные шаги анализа

### 1. Установка и импорт библиотек
Установка необходимых пакетов(xgboost, catboost, shap) и импорт библиотек для работы с данными, построения моделей и визуализации.

### 2. Загрузка и подготовка данных
- Загрузка датасета из CSV-файла
- Отбор релевантных признаков(17 признаков)

### 3. Разделение данных
- Обучающая выборка: 70%
- Валидационная выборка: 30%
- Фиксация random_state=1 для воспроизводимости

### 4. Обучение базовой модели XGBoost
- Обучение с параметрами по умолчанию
- Оценка качества по ROC-AUC
- Получение baseline для сравнения

### 5. Настройка гиперпараметров XGBoost
Оптимизация параметров для борьбы с переобучением:
- "reg_lambda" - L2 регуляризация
- "max_depth=4" - ограничение глубины
- "gamma=10" - минимальное улучшение для разбиения
- "learning_rate=0.1" - темп обучения

### 6. Обучение XGBoost с ранней остановкой
- Использование формата DMatrix для эффективности
- Ранняя остановка при отсутствии улучшений (50 итераций)
- Отслеживание метрик на обучающей и валидационной выборках

### 7. Визуализация процесса обучения
- График изменения ROC-AUC на обучающей и валидационной выборках
- Анализ сходимости и признаков переобучения

### 8. Кросс-валидация XGBoost
- 3-фолдовая кросс-валидация
- Оценка стабильности модели
- Расчет среднего значения и стандартного отклонения

### 9. Обучение базовой модели CatBoost
- Обучение с параметрами по умолчанию
- Сравнение с XGBoost

### 10. Настройка гиперпараметров CatBoost
- "l2_leaf_reg=10" - L2 регуляризация
- "max_depth=6" - ограничение глубины
- "learning_rate=0.01" - низкий темп обучения
- "early_stopping_rounds=50" - ранняя остановка

### 11. Обучение CatBoost с визуализацией
- Использование формата Pool
- Визуализация обучения в реальном времени
- Отслеживание динамики качества

### 12. Кросс-валидация CatBoost
- 3-фолдовая кросс-валидация
- Автоматическая визуализация результатов
- Оценка стабильности

### 13. Сравнение результатов
Анализ и сравнение производительности моделей XGBoost и CatBoost по метрике ROC-AUC.
